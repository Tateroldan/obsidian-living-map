# Search learnings before giving an opinion

Before recommending something or deciding how to do it, Claude searches `Learnings/` (Grep by word or by `area:`) and reads only the notes that apply. That reuses what was already expensive to learn and avoids repeating mistakes.

**How to apply it:** a short search first; if there is nothing, carry on and, when done, write the new learning.
