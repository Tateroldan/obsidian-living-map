# One learning, one idea, always linked

A note of 3 to 6 lines with a single idea: what happened, the rule and how to apply it. It ends with **Connects with:** pointing to other learnings. A note without links is an orphan and nobody finds it; a long note mixes ideas and is not reused.

**How to apply it:** if unsure whether to extend or create, create a new one and link it. Never overwrite: if it changes, write a new note with "supersedes [[...]]".
