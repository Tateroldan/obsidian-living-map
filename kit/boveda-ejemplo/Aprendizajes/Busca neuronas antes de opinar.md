# Busca neuronas antes de opinar

Antes de dar una recomendación o decidir cómo hacer algo, Claude busca en `Aprendizajes/` (Grep por palabra o por `area:`) y lee solo las neuronas que aplican. Así se aprovecha lo que ya costó aprender y no se repiten errores.

**Cómo aplicarla:** una búsqueda corta primero; si no hay nada, se sigue y, al terminar, nace la neurona.
