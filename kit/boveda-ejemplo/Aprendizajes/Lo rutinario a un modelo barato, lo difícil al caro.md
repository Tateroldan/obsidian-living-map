# Lo rutinario a un modelo barato, lo difícil al caro

Ordenar notas, buscar, poner propiedades y procesar la bandeja no necesitan el mejor modelo: se delegan al agente `bibliotecario` (modelo barato). El modelo caro se guarda para decidir, diseñar y revisar. Antes de gastar tokens, un script de reglas (`router_bandeja.py`) resuelve lo obvio sin ningún modelo.

**Cómo aplicarla:** orden de escalada: script → modelo barato → modelo caro → tú. Lo que mezcla temas prohibidos va directo a ti.
